Frequently asked questions

Where are my notes saved?

Everything is saved automatically on your Mac, in Note Note’s private storage. Nothing is uploaded anywhere. To see your attachments in Finder, open Help → Note Note Help in the app and choose the option to open the storage folder.

How do I back up or move my boards to another Mac?

Choose File → Export with Attachments (.zip) for each board, copy the files to the other Mac, then use File → Import Project…. Time Machine backups also include Note Note’s data.

I used the earlier downloadable version. Will my boards carry over?

Yes, in two steps. In the old version, choose File → Export with Attachments (.zip) for each board. Then, in the App Store version, choose File → Import Project… and select those files. You can also double-click a .nnn file to open it in Note Note.

  • ⌘F Search all boards · ⌘L Show/hide sidebar
